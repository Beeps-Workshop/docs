# Vool

A retextured wool, in all 16 dye colors, with matching carpets. Purely decorative — it behaves
exactly like vanilla wool and carpet (same hardness, same sounds, still catches fire from lava).

Get it by feeding dyed wool to an [Ender Clam](../FunctionalBlocks/EnderClam.md).
