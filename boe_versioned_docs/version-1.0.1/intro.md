**_A Mod that attempts to add new content to the end without ruining the desolate feel of the dimension._**

![A showcase of the blocks added by this mod in the 1.0 version](https://cdn.modrinth.com/data/SigAnrwo/images/d9fd8832b61f445e0675507be1aca946089d7e4a.png)

## Functional Blocks/Items
![Separator](https://cdn.modrinth.com/data/cached_images/67b87a7b35c2463aa362c262d80c26da971d7c51.png)
- **Membrane**: A new slime-like block that generates in blobs in the end outer isles.
- **Membrane Bubble**: A Block that generates on the surface of the outer end isles, when stepped on it will launch any entity upwards and grant them temporary elytra flight
- **Membrain**: A EXP Storage block that will pull in nearby exp orbs. Can be powered by redstone or broken to release it's EXP. Can be used to create EXP bottles or revive dead coral.
- **Ender Clam**: A Block that can be fed items to transmute them into other items
- **Purpur Jar**: A Jar with a single inventory slot.
- **Dream Catcher**: Can be found in the Shelter. Blocks phantoms from spawning in a large radius
- **Phantom Glass**: A Special glass that will become non-solid when observed.
- **Gateway Compass**: A Compass that will always point to the nearest end gateway

## Decorative Blocks
![Separator](https://cdn.modrinth.com/data/cached_images/67b87a7b35c2463aa362c262d80c26da971d7c51.png)
- **Polished PurPur**
- **Purpur Tiles**
- **Kao**: A Purplish version of Oak that generates in the end. The pressure plate will stay pressed until right clicked and the button will stay powered until pressed.
- **Vool**: A slightly differently tinted wool variant with carpets.
- **Elyum**: A Nylium variant for the end.
