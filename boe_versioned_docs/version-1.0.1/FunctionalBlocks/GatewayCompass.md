# Gateway Compass

A compass that always points to the nearest End gateway — the ones on outer end islands that lead
back to the main island.

## Crafting
Feed a regular compass to an [Ender Clam](./EnderClam.md) — there's no crafting-table recipe for
it.

## Usage
Only works in the End. While there, it searches a 512-block radius every few seconds for gateways
that lead back toward the main island (ignoring nearby, useless ones) and points at the nearest
one it finds. Outside the End it just idles like a normal compass in an invalid dimension.

Getting close to the gateway it's tracking grants an advancement for finding your way home.
