# Troubleshooting

## Is the plugin loaded?
Does the plugin show up in `/pl` and is it green? If it's not there, you might not have installed
it correctly or haven't restarted the server yet.

## Mending still repairs Netherite normally
Make sure you're running a supported server platform (Spigot, Paper, PurPur or Folia) on
Minecraft 1.18 or newer, and that the plugin actually loaded (see above). FiniteNetherite only
changes how mending behaves on Netherite gear — it doesn't touch mending on other materials.

## Check your logs!
Check your console for errors on server start. You should also skim through the `latest.log`
file in your server's `logs` folder for any errors mentioning FiniteNetherite.
