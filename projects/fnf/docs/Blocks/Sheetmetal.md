# Sheetmetal

Corrugated metal panelling, in copper and iron.

## Placing it
Sheetmetal faces you when placed, and the corrugation rotates with it — the same trick glazed
terracotta uses. Turning blocks against each other lets a wall of it read as a deliberate pattern
rather than a flat repeat.

It's a full solid block, so it behaves normally for building.

## Crafting
Six ingots in a 3×2 block, giving six panels.
