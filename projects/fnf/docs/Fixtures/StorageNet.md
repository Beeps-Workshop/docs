# Storage Net

A net slung along a wall holding a double chest's worth of items.

![Wall-mounted storage nets](https://cdn.modrinth.com/data/giBTRDbb/images/dc14d4d22d2d810b4a53fa60ec4fa19fb157127f.png)

## Placing it
Right-click a **wall**. It is 2 blocks wide, centered on the block you placed. This means it extends onto both neighbors.

Because it's wider than a block, **two can't sit on adjacent blocks**

Only the block you attach it to needs to be solid, so a net can overhang the end of a wall if you
want it to.

## Using it
The net stores the same amount of items as a normal double chest.

A few of the items inside are visible resting in the net, so you can tell a stocked net from an
empty one at a glance without opening it.

Breaking it drops the net and everything inside.
