# Installing

## Requirements
- Minecraft 1.21.1
- [NeoForge](https://neoforged.net/) 21.1.241 or newer (any 21.1.1 build)

## Installation Steps
1. Install [NeoForge](https://neoforged.net/) for Minecraft 1.21.1 if you haven't already.
2. Download the latest version of BMCRM from [Modrinth](https://modrinth.com/mod/bmcrm) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/beeps-mean-crystalline-resource-machine-bmcrm).
3. Stop your Minecraft instance/server if it is currently running.
4. Copy the downloaded jar file into your `mods` folder.
5. Start Minecraft. The mod will load automatically.

## Optional integrations
BMCRM doesn't require any other mods, but will automatically hook into these if they're installed:
- [JEI](https://modrinth.com/mod/jei) - recipes for crystals, modulators and machines
- [JADE](https://modrinth.com/mod/jade) - in-world tooltips for crystals
- [Create](https://modrinth.com/mod/create) - Ponder scenes for BMCRM's blocks
- [AlmostUnified](https://modrinth.com/mod/almostunified) - respects altered outputs
