# Purpur Jar

A single-slot storage jar that holds any one item stack.

## Using it
- Right-click empty-handed to withdraw the full stored stack.
- Right-click while holding an item to deposit it into an empty jar.
- Right-click with the same item you've already stored to top up the jar's stack.
- Right-click with a different item to swap it for whatever's currently stored.

Some Purpur Jars found in the world are loot-jars — the first time you interact with one, its
contents are rolled from a loot table instead of starting empty.

Breaking a jar drops whatever's stored inside it.
