# Ender Clam

A block that transmutes items — feed it something, wait, and get something else back.

## Using it
Right-click the clam with an item to close it around that item and start processing. Right-click
it empty-handed while it's working to cancel and get your item back. When it finishes, the clam
reopens and spits the result out in front of it.

## Recipes
Recipes are data-driven, so servers can add their own, but a few notable built-in ones:

| Input           | Output              | Time     |
|-----------------|---------------------|----------|
| Cobblestone     | End Stone           | 5s       |
| Stone Bricks    | End Stone Bricks    | 5s       |
| Apple           | Chorus Fruit        | 3s       |
| Magma Cream     | Phantom Membrane    | 3s       |
| Ender Eye       | Ender Pearl          | 3s       |
| Sea Pickle      | End Rod             | 4s       |
| Compass         | [Gateway Compass](./GatewayCompass.md) | 5s |
| Glass Bottle    | Dragon's Breath     | 6s       |
| Obsidian        | Crying Obsidian     | 60s      |
| Nautilus Shell  | Shulker Shell       | 120s     |
| Any dyed wool   | matching Vool wool  | 1.5–2s   |

If nothing matches, the clam just returns your item after a couple of seconds.
