# Installing

## Requirements
- Minecraft 1.20.1
- [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/) 47.4.5 or newer

## Installation Steps
1. Install [Forge](https://files.minecraftforge.net/net/minecraftforge/forge/) for Minecraft
   1.20.1 if you haven't already.
2. Download the latest version of Beep's Other End from [Modrinth](https://modrinth.com/mod/beeps-other-end) or [CurseForge](https://www.curseforge.com/minecraft/mc-mods/beeps-other-end).
3. Stop your Minecraft instance/server if it is currently running.
4. Copy the downloaded jar file into your `mods` folder.
5. Start Minecraft. The mod will load automatically.

## Verification
Generate or travel to a new End island — Membrane and Membrane Bubble blocks should start
appearing on the outer end isles if the mod loaded correctly.
