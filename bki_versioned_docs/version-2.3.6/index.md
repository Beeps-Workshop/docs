## About

BetterKeepInventory (also written as Better Keep Inventory) is a KeepInventory plugin for Minecraft servers.

Do you want to use the KeepInventory gamerule but dislike how it completely removes any risk with death? With this plugin you get to choose how punishing death should be!
Using a rich rule-based configuration system you get fine control over exactly what happens to players when they die!

## Features
- ✅ **Rich rule-based configuration system**
- ✅ **Use Permissions, Worlds or [PlaceholderAPI](https://modrinth.com/plugin/placeholderapi) conditions**
- ✅ **Make items drop**
- ✅ **Control XP Level**
- ✅ **Apply Durability Damage**
- ✅ **Re-apply hunger level**
- ✅ **Take Money from players**
- ✅ **Expandable via the [Developer API](https://workshop.beepsterr.com/bki/API)**
- ✅ **Supports Spigot, Paper, Purpur & Folia**

## Compatibility
- **Server software:** Spigot, Paper, Purpur and Folia
- **Minecraft:** 1.21 and newer, including 26.x
- **Java:** 21 or newer

Running an older Minecraft version? Older releases are still available on [Modrinth](https://modrinth.com/plugin/betterkeepinventory/versions).
