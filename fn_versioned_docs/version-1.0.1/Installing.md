# Installing

## Requirements
- Java 8 or higher
- A Minecraft Server running Spigot, Paper, PurPur or Folia (1.18 or newer)

## Installation Steps
1. Download the latest version of FiniteNetherite from [Modrinth](https://modrinth.com/mod/finitenetherite) or [CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/finitenetherite)
2. Stop your Minecraft server if it is currently running.
3. Copy the downloaded jar file into your server's `plugins` directory.
4. Start your Minecraft server. The plugin will load automatically.

## Verification
To verify that the plugin has been installed correctly, check for `FiniteNetherite` in the `/pl` (or `/plugins`) list — it should show up green.
